# v1 source-contract admission

This feature admits a narrow secret-free toolkit and render/check CLI for
Authentik 2026.5.2 only. It does not create a daemon, remote-apply path, public
client support, tag, hosted Release, publication, deployment, or live-tenant
mutation.

The runtime gate is a disposable two-application import and re-import. It is not
complete until every generated provider, application, group, flow, prompt,
stage, stage binding, policy binding, isolation boundary, count, and generated
secret invariant has an independent database assertion and cleanup is proven.

Consumer admission reuses exact Mail evidence where the toolkit revision and
consumer blobs match. Board provenance remains historical. Missing WorldWeave
proof is represented only by an isolated producer fixture and must not be
reported as a deployment or consumer pin.

Evidence and independent reviews belong under evidence/ and review/. The
canonical workflow state remains workflow.toml.
